# MINI GT PROTOTYPES

Статический каталог прототипов MINI GT, показанных на выставках до предзаказа или релиза. Сайт работает без сборки, базы данных и внешних сервисов: данные и изображения находятся в этой папке. Отменённые модели отмечены заметной меткой `CANCELLED` и доступны через отдельный фильтр.

## Опубликовать на GitHub и Vercel

1. Создайте пустой репозиторий GitHub и загрузите в него **содержимое этой папки**.
2. В Vercel выберите `Add New → Project`, импортируйте репозиторий.
3. Framework Preset оставьте `Other`; Build Command и Output Directory не заполняйте.
4. Нажмите `Deploy`.

## Проверить на компьютере

Откройте терминал в этой папке и запустите:

```bash
python -m http.server 8080
```

После этого перейдите по адресу `http://localhost:8080`.

## Обновить каталог из Excel

Скрипт считывает все листы книги и извлекает встроенные Excel-фото, в том числе дополнительные изображения и колонки `REAL CAR`. Строки с жёлтой заливкой из исходной книги автоматически получают статус `CANCELLED`.

```bash
python scripts/extract_catalog.py "C:\path\to\Mini GT.xlsx"
```

Нужен Python 3 с библиотекой `openpyxl` (`pip install openpyxl`). Скрипт перезапишет `assets/data/models.json` и папку `assets/images`, а интерфейс сайта менять не потребуется.

Коллекции распознаются из названия модели: `Bond 007`, `Fast & Furious`, `Korean Collection` и любые фразы в скобках, которые заканчиваются на `Collection`. Чтобы добавить модель в новую коллекцию, достаточно вписать её название в скобках в Excel.
