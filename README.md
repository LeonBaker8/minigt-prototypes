# MINI GT Prototype Archive

Статический каталог прототипов MINI GT, показанных на выставках до предзаказа или релиза. Сайт работает без сборки, базы данных и внешних сервисов: данные и изображения находятся в этой папке. Отменённые модели отмечены заметной меткой `CANCELLED` и доступны через отдельный фильтр.

## Возможности

- Новый тёмный профессиональный дизайн с каталогом, коллекциями и брендами.
- Крупный баннер выбранной категории с логотипом и количеством прототипов.
- Логотипы в оригинальных цветах и иконка мотоцикла в стиле интерфейса.
- Дата последнего обновления архива автоматически берётся из Excel при публикации.
- Просмотр фотографий показывает изображения в их исходном размере, без размытия из-за растягивания.
- Подпись дополнительного снимка реального автомобиля везде отображается как `Real Photo`.
- Отдельные разделы для отменённых и потенциальных моделей.

## Проверить на компьютере

Откройте терминал в этой папке и запустите:

```bash
python -m http.server 8080
```

После этого перейдите по адресу `http://localhost:8080`.

## Обновить каталог из Excel

Скрипт считывает все листы книги и извлекает встроенные Excel-фото, в том числе дополнительные изображения и колонки `REAL CAR`. Строки с жёлтой заливкой из исходной книги автоматически получают статус `CANCELLED`.

Лист `Potential Models` импортируется в отдельный синий раздел `Potential`. Для него ожидаются столбцы `MODEL`, `DATE` и фотографии. Бренд определяется по названию модели. Потенциальные модели не смешиваются с основным каталогом или отменёнными моделями.

```bash
python scripts/extract_catalog.py "C:\path\to\Mini GT.xlsx"
```

Нужен Python 3 с библиотекой `openpyxl` (`pip install openpyxl`). Скрипт перезапишет `assets/data/models.json`, `assets/data/catalog-meta.js` и папку `assets/images`, а интерфейс сайта менять не потребуется. В `catalog-meta.js` находятся дата последнего сохранения Excel и актуальные счётчики моделей для сайта.

Коллекции распознаются из названия модели: `Bond 007`, `Fast & Furious`, `Korean Collection` и любые фразы в скобках, которые заканчиваются на `Collection`. Чтобы добавить модель в новую коллекцию, достаточно вписать её название в скобках в Excel.

## Обновить и опубликовать одной командой

Не загружайте фото через форму `Upload files` на GitHub: у неё есть ограничение в 100 файлов. Откройте PowerShell **в этой папке проекта** и выполните одну команду:

```powershell
.\publish-site.ps1 "C:\path\to\Mini GT.xlsx"
```

Скрипт проверит репозиторий, извлечёт актуальные данные и фото, создаст Git-коммит и отправит его на GitHub. Vercel автоматически начнёт новый деплой.
