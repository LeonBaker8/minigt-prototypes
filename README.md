# MINI GT PROTOTYPES

Статический каталог прототипов MINI GT, показанных на выставках до предзаказа или релиза. Сайт работает без сборки, базы данных и внешних сервисов: данные и изображения находятся в этой папке. Отменённые модели отмечены заметной меткой `CANCELLED` и доступны через отдельный фильтр.

## Опубликовать на GitHub и Vercel

1. Создайте пустой репозиторий GitHub и загрузите в него **содержимое этой папки**.
2. В Vercel выберите `Add New → Project`, импортируйте репозиторий.
3. Framework Preset оставьте `Other`; Build Command и Output Directory не заполняйте.
4. Нажмите `Deploy`.

Важно: загружайте папку целиком, а не только файлы из её верхнего уровня. После публикации адрес `https://ваш-сайт.vercel.app/assets/data/models.json` должен открывать JSON со списком моделей; иначе каталог останется пустым.

### Первая публикация для репозитория LeonBaker8/minigt-prototypes

Чтобы не использовать веб-форму GitHub с ограничением в 100 файлов, откройте PowerShell в этой папке и запустите:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\publish-first-time.ps1
```

Скрипт сначала создаст чистый клон правильного GitHub-репозитория, проверит `origin`, затем добавит каталог вместе с изображениями и отправит один коммит. Он остановится при любой ошибке клонирования или авторизации, не создавая вложенный ошибочный репозиторий.

## Проверить на компьютере

Откройте терминал в этой папке и запустите:

```bash
python -m http.server 8080
```

После этого перейдите по адресу `http://localhost:8080`.

## Обновить каталог из Excel

Скрипт считывает все листы книги и извлекает встроенные Excel-фото, в том числе дополнительные изображения и колонки `REAL CAR`. Строки с жёлтой заливкой из исходной книги автоматически получают статус `CANCELLED`.

```bash
python scripts/extract_catalog.py "C:\path\to\Mini GT.xlsx"
```

Нужен Python 3 с библиотекой `openpyxl` (`pip install openpyxl`). Скрипт перезапишет `assets/data/models.json` и папку `assets/images`, а интерфейс сайта менять не потребуется.

Коллекции распознаются из названия модели: `Bond 007`, `Fast & Furious`, `Korean Collection` и любые фразы в скобках, которые заканчиваются на `Collection`. Чтобы добавить модель в новую коллекцию, достаточно вписать её название в скобках в Excel.

## Следующие обновления без лимита GitHub

Не загружайте фото через форму `Upload files` на GitHub: у неё есть ограничение в 100 файлов. После первоначальной настройки репозитория откройте PowerShell **в локальной папке-клоне GitHub-репозитория** и выполните одну команду:

```powershell
.\update-catalog.ps1 "C:\path\to\Mini GT.xlsx"
```

Скрипт сам извлечёт актуальные данные и фото, добавит изменения в Git, создаст коммит и отправит его на GitHub. Файлов может быть сколько угодно; Vercel автоматически начнёт новый деплой. Изображения остаются отдельными, поэтому сайт подгружает их только по мере просмотра, а не заставляет посетителя скачивать весь архив сразу.
